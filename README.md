# A Web Calculator 

I made this simple browser based calculator I built as part of my intern project. I wanted to move away from basic console applications and see if I could build something that actually looks like a real calculator.

## Why I Built This
This project was a great way for me to get comfortable with the "Big Three" of web development: HTML, CSS, and JavaScript. My goal was to move from writing code that just runs in a black terminal window to creating an actual user interface that someone can interact with.

## What’s Under the Hood
*   **HTML5:** Used to build the structure—basically just a screen and a bunch of buttons.
*   **CSS:** I used CSS Grid to get everything lined up perfectly. Getting those buttons to behave was definitely the trickiest part!
*   **JavaScript:** This is the "brain." I used it to grab the clicks and handle the math. 

## Lessons Learned
The coolest thing I learned here was how to link the user's clicks in the browser to the logic in my JS file. I also realized how much fun it is to make something visual compared to just text-based code!

## How to Try It
It’s super simple:
1. Just download the files.
2. Open `index.html` in any browser (Chrome, Edge, or Firefox).
3. Start clicking!

## Future Goals
Right now, it handles the basics, but next, I want to:
*   Add keyboard support (so you don't *have* to use your mouse).
*   Maybe add a dark mode because, let's be honest, everything looks better in dark mode.
