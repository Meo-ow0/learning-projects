## About

This repository collects the small practice projects I built while learning to program. They started as separate repositories and are now merged into one, with their commit history kept, so my profile can focus on my bigger projects.

These are learning exercises, not finished products. They show where I started and what I practiced.

## How to run a project

Every folder is independent. Open the one you want and follow the steps in its README.

```bash
# Clone the whole collection
git clone https://github.com/Meo-ow0/learning-projects.git
cd learning-projects

# Open the folder you want, for example Java
cd java/java-programming
```

- **Android projects:** open the folder in Android Studio and let Gradle sync.
- **Java projects:** compile with `javac` and run with `java`, or open them in an IDE like IntelliJ IDEA.
- **C project:** compile with `gcc` and run the output file.
